# Finanças e Investimentos

Prompts para análise de empresas, demonstrações financeiras, valuation, investimentos e avaliação de riscos.

## Como usar

- Informe período, moeda, unidades, fontes e premissas.
- Diferencie dados reportados, estimativas e hipóteses.
- Confira cálculos e fontes originais; não trate respostas como recomendação financeira personalizada.
- Não compartilhe dados financeiros pessoais ou confidenciais.
