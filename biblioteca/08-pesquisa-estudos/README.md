# Pesquisa e Estudos

Pesquisa bibliográfica, síntese, planejamento de estudos, explicações didáticas e revisão crítica.

## Como organizar
- Use arquivos individuais no padrão `SIGLA-NNN-nome-curto.md`.
- Mantenha os prompts específicos nesta categoria.
- Para prompts ainda não testados, mantenha o status `Rascunho`.
- Consulte `../PROMPT_TEMPLATE.md` para criar novos materiais.
