# Análise de Dados

## Prompts disponíveis
- DADOS-001 — Planejamento de análise de dados
- DADOS-002 — Limpeza e qualidade dos dados
- DADOS-003 — Análise exploratória (EDA)
- DADOS-004 — SQL e construção de consultas
- DADOS-005 — Planejamento de dashboard no Power BI
- DADOS-006 — Relatório e apresentação de insights
