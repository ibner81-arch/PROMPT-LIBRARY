# DADOS-006 — Relatório e apresentação de insights

- **Categoria:** Análise de Dados
- **Status:** Rascunho
- **Dificuldade:** Básica/intermediária
- **Ferramentas:** ChatGPT / Claude / Word / PowerPoint
- **Última revisão:** 2026-11-11

## Objetivo
Comunicar resultados com clareza, evidências e recomendações proporcionais.

## Quando usar
Ao transformar uma análise em relatório, apresentação ou resumo executivo.

- {{PUBLICO}}
- {{OBJETIVO}}
- {{RESULTADOS}}

## Prompt

```text
Atue como analista de dados e comunicador de resultados.
PÚBLICO: {{PUBLICO}}
OBJETIVO: {{OBJETIVO}}
RESULTADOS: {{RESULTADOS}}
LIMITAÇÕES: {{LIMITACOES}}
FORMATO: {{FORMATO}}

Estruture o material com resumo executivo; contexto e pergunta; fontes, período,
método e definições; resultados com números; interpretação e explicações
alternativas; limitações; recomendações ligadas às evidências; e próximas análises.

Não crie números, fontes ou conclusões ausentes. Separe fato observado,
interpretação e recomendação. Se os resultados não sustentarem uma conclusão,
diga isso explicitamente. Adapte a linguagem ao público sem omitir ressalvas.
```

## Como avaliar o resultado
- [ ] Números foram conferidos com a fonte?
- [ ] Fatos, interpretações e recomendações estão separados?
- [ ] Limitações e explicações alternativas estão visíveis?
- [ ] Recomendações são proporcionais às evidências?
