# Produtividade e Administração

Prompts para Excel, organização de processos, planejamento, gestão de tarefas e produtividade.

## Como usar

- Indique o objetivo, as ferramentas disponíveis, os prazos e as restrições.
- Peça passos e resultados verificáveis, adequados à rotina real.
- Remova informações pessoais ou confidenciais antes de usar uma ferramenta de IA.
