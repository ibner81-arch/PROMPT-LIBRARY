# Programação

Prompts para Python, SQL, JavaScript, depuração, revisão, refatoração e automação de tarefas de código.

## Como usar

- Descreva o objetivo, a linguagem, as versões e o contexto relevante.
- Compartilhe apenas os trechos de código necessários e remova segredos.
- Peça explicação, testes e limitações; revise as alterações antes de executá-las.
