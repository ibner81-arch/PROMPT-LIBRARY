# Design e Criatividade

Prompts para identidade visual, layouts, direção de arte, conteúdo criativo e imagens.

## Como usar

- Informe público, finalidade, formato, referências e restrições da peça.
- Separe referências de estilo de elementos que devem ser reproduzidos literalmente.
- Verifique direitos de uso, marcas, licenças e adequação antes de publicar o resultado.
