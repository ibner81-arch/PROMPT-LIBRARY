# WEB-003 — Auditoria de UI/UX

- **Categoria:** Desenvolvimento Web
- **Status:** Rascunho
- **Dificuldade:** Intermediária
- **Ferramentas:** ChatGPT / Claude / Antigravity
- **Última revisão:** 2026-11-11

## Objetivo
Avaliar interface, clareza, navegação e acessibilidade de um site.

## Prompt

```text
Atue como especialista sênior em UI/UX e acessibilidade.
Analise o site ou as telas fornecidas: {{URL_OU_DESCRICAO_OU_IMAGENS}}.
Público-alvo: {{PUBLICO}}.
Objetivo principal do site: {{OBJETIVO}}.

Avalie:
1. Hierarquia visual e legibilidade.
2. Consistência de cores, tipografia, espaçamentos e componentes.
3. Navegação, arquitetura da informação e clareza dos textos.
4. Experiência em celular, tablet e desktop.
5. Acessibilidade: contraste, foco, teclado, rótulos e textos alternativos.
6. Estados de carregamento, vazio, erro e sucesso.
7. Confiança, clareza de chamadas para ação e prevenção de erros.

Para cada problema, informe:
- Evidência observada;
- Impacto no usuário;
- Prioridade (crítica, alta, média ou baixa);
- Recomendação concreta.

Não elogie genericamente nem invente problemas que não foram observados.
Ao final, proponha um plano de melhorias por prioridade. Não altere o código
antes de apresentar o diagnóstico.
```

## Como avaliar
- [ ] Problemas apoiados em evidências.
- [ ] Acessibilidade incluída.
- [ ] Recomendações priorizadas.
