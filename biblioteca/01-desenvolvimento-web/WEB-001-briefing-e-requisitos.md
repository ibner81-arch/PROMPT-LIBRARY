# WEB-001 — Briefing e levantamento de requisitos

- **Categoria:** Desenvolvimento Web
- **Status:** Rascunho
- **Dificuldade:** Básica
- **Ferramentas:** ChatGPT / Claude
- **Última revisão:** 2026-11-11

## Objetivo
Transformar uma ideia inicial em requisitos claros antes de escrever código.

## Prompt

```text
Atue como analista de produto e desenvolvedor web sênior.
Ajude a transformar a ideia abaixo em um briefing claro.

PROJETO: {{DESCRICAO_DO_PROJETO}}
PÚBLICO-ALVO: {{PUBLICO}}
PROBLEMA QUE RESOLVE: {{PROBLEMA}}
RESTRIÇÕES: {{PRAZO_ORCAMENTO_TECNOLOGIAS}}

Entregue:
1. Resumo do produto em até 5 linhas.
2. Perfis de usuários e suas necessidades.
3. Funcionalidades essenciais, separadas das desejáveis.
4. Fluxos principais de navegação.
5. Requisitos não funcionais: acessibilidade, segurança, desempenho e responsividade.
6. Dados que precisam ser armazenados e cuidados de privacidade.
7. Riscos, dúvidas e premissas.
8. Critérios objetivos de aceite para cada funcionalidade.

Não invente decisões que dependem do responsável pelo projeto.
Liste as perguntas pendentes e espere minhas respostas antes de tratar
o escopo como fechado. Não escreva código nesta etapa.
```

## Como avaliar
- [ ] Requisitos compreensíveis e verificáveis.
- [ ] Dúvidas e premissas explicitadas.
- [ ] Funcionalidades essenciais separadas das futuras.
